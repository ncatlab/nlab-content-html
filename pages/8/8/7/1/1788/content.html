The 3Qbit code

The classical case

A bit b∈{0,1}b \in \{0,1\} stored or transmitted in a noisy medium may get flipped, b↦b⊕1b \mapsto b \oplus 1, with some small probability pp. The simplest remedy is redundancy: encode each logical bit by a triple of equal physical bits,

0↦000,1↦111. 0 \;\mapsto\; 000 \,, \qquad 1 \;\mapsto\; 111 \,.

If at most one of the bits b 1b 2b 3b_1 b_2 b_3 gets flipped, its position is determined by the two parities

s 1≔b 1⊕b 2,s 2≔b 2⊕b 3, s_1 \;\coloneqq\; b_1 \oplus b_2 \,, \qquad s_2 \;\coloneqq\; b_2 \oplus b_3 \,,

which vanish on the codewords. This pair is the error syndrome:

(s 1,s 2)=(0,0) ⇒no error (s 1,s 2)=(1,0) ⇒bit 1 flipped (s 1,s 2)=(1,1) ⇒bit 2 flipped (s 1,s 2)=(0,1) ⇒bit 3 flipped \begin{aligned} (s_1, s_2) = (0,0) & \;\;\Rightarrow\;\; \text{no error} \\ (s_1, s_2) = (1,0) & \;\;\Rightarrow\;\; \text{bit 1 flipped} \\ (s_1, s_2) = (1,1) & \;\;\Rightarrow\;\; \text{bit 2 flipped} \\ (s_1, s_2) = (0,1) & \;\;\Rightarrow\;\; \text{bit 3 flipped} \end{aligned}

Flipping the indicated bit back (equivalently: taking the majority vote) recovers the logical bit. This fails only if two or more bits were flipped, which happens with probability 3p 2−2p 3<p3p^2 - 2p^3 \lt p (for p<1/2p \lt 1/2).

Here the syndrome is obtained in the most direct way: by reading out, hence by measuring, the three physical bits. Classically, this does no harm.

The issue with the quantum case

Now the information to be protected is the state |ψ⟩=α|0⟩+β|1⟩\vert \psi \rangle = \alpha \vert 0 \rangle + \beta \vert 1 \rangle of a qbit, hence the amplitudes α,β∈ℂ\alpha, \beta \in \mathbb{C}. Copying |ψ⟩↦|ψ⟩ ⊗3\vert\psi\rangle \mapsto \vert\psi\rangle^{\otimes 3} is ruled out by the no-cloning theorem, but the linear extension of the classical encoding,

|ψ⟩↦|ψ L⟩≔α|000⟩+β|111⟩, \vert \psi \rangle \;\mapsto\; \vert \psi_L \rangle \;\coloneqq\; \alpha \vert 000 \rangle + \beta \vert 111 \rangle \,,

is fine: two CNOT gates implement it on |ψ⟩⊗|00⟩\vert\psi\rangle \otimes \vert 00 \rangle (see below). A flip of the iith qbit now acts by the Pauli operator X iX_i (with X 0≔1X_0 \coloneqq 1 for the error-free case), e.g.

X 2|ψ L⟩=α|010⟩+β|101⟩. X_2 \vert \psi_L \rangle \;=\; \alpha \vert 010 \rangle + \beta \vert 101 \rangle \,.

Applying the classical strategy verbatim means measuring the three qbits in the computational basis. This does reveal the syndrome, but already the first measurement collapses the state onto one of its two branches (here |010⟩\vert 010\rangle or |101⟩\vert 101 \rangle, with probability |α| 2\vert\alpha\vert^2 or |β| 2\vert\beta\vert^2, respectively). The error is diagnosed, but the amplitudes α,β\alpha, \beta (the very data to be protected) are lost.

Notice, however, that the syndrome takes the same value on both branches (here (s 1,s 2)=(1,1)(s_1, s_2) = (1,1) for |010⟩\vert 010\rangle as well as for |101⟩\vert 101\rangle). So each X i|ψ L⟩X_i \vert \psi_L\rangle is a joint eigenstate of the parity observables Z 1Z 2Z_1 Z_2 and Z 2Z 3Z_2 Z_3, with eigenvalues (−1) s 1(-1)^{s_1} and (−1) s 2(-1)^{s_2}. The individual bits must not be measured, but their parities may.

This motivates adjoining auxiliary ancilla qbits onto which the parities are imprinted by unitary gates. A quantum measurement of just the ancillas is then a measurement on the total system which reveals the syndrome without collapsing the encoded state.

The proper quantum case

Concretely, adjoin two ancilla qbits in state |00⟩\vert 00 \rangle and imprint on them the parities by four CNOT gates:

|b 1b 2b 3⟩⊗|00⟩longmapsto|b 1b 2b 3⟩⊗|b 1⊕b 2,b 2⊕b 3⟩. \vert b_1 b_2 b_3 \rangle \otimes \vert 00 \rangle \;\longmapsto\; \vert b_1 b_2 b_3 \rangle \otimes \vert b_1 \oplus b_2 ,\, b_2 \oplus b_3 \rangle \,.

Since the parities agree on both branches of X i|ψ L⟩X_i \vert \psi_L \rangle, this unitary maps

X i|ψ L⟩⊗|00⟩longmapstoX i|ψ L⟩⊗|s 1s 2⟩. X_i \vert \psi_L \rangle \otimes \vert 00 \rangle \;\longmapsto\; X_i \vert \psi_L \rangle \otimes \vert s_1 s_2 \rangle \,.

This being a product state, measuring the ancillas yields the syndrome (s 1,s 2)(s_1, s_2) with certainty and leaves the code qbits in X i|ψ L⟩X_i \vert\psi_L\rangle, uncollapsed. Applying X iX_i once more, with ii read off from the syndrome table above, restores |ψ L⟩\vert \psi_L \rangle.

The code protects only against single bit flips. Conjugating with Hadamard gates turns it into the analogous phase flip code (protecting against single Z iZ_i-errors), and nesting the two yields Shor’s 9-qbit code.
